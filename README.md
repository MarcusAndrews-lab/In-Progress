<h2>Ducky Scripts</h2>

A list of scripts to run on HID devices that act like keyboards. The "tools" scripts are safe to use to help with automation. The "security" scripts should be run with extreme 
caution and only if you know and understand what they are doing. Use of such scripts outside of your own authorized devices or that you do not have permission to access can be 
punished. By using such scripts you accept full responsibility for your actions. [Computer Fraud and Abuse Act (CFAA)](https://www.nacdl.org/Landing/ComputerFraudandAbuseAct)
